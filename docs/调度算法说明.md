# 复习调度算法说明（关键部分，修改前必须说明）

> 本文件是复习调度算法的唯一权威说明。**没有在本文档中说明理由并获得确认，
> 不允许修改 `app/srs.py`、前端评分预览逻辑或队列生成逻辑。**

## 1. 当前算法：FSRS-6（py-fsrs 6.3.1）

2026-08-07 起，复习调度由原来的“质数间隔”经验公式切换为
[FSRS-6](https://github.com/open-spaced-repetition/free-spaced-repetition-scheduler)
（Python 实现 `py-fsrs`，Anki 自 25.07 起默认使用的算法）。

### 切换理由

- FSRS 基于 DSR 记忆模型（Difficulty / Stability / Retrievability），
  用数亿次真实复习数据拟合的默认参数，比固定间隔序列更接近真实遗忘曲线；
- 官方和社区基准显示，在相同目标保持率下，FSRS 比 SM-2/固定序列
  少约 20–30% 的复习量；
- 开源且长期维护，有 Python/Rust/TypeScript 官方实现，适合本项目长期低维护；
- 它支持“提前/延后复习”，卡片状态（稳定度、难度）会随每次评分持续进化。

## 2. 评分四档，与 FSRS 一一对应

| 界面评分 | 含义 | FSRS Rating |
|---|---|---|
| `again` | 重来 | `Again`（1） |
| `hard` | 困难 | `Hard`（2） |
| `good` | 认识 | `Good`（3） |
| `easy` | 简单 | `Easy`（4） |

四键直接透传给 FSRS，不做任何改编。

## 3. 调度器配置

- 目标保持率 `desired_retention = 0.9`（90%）；
- 学习步骤 `learning_steps = (0s)`（用户确认）：学习状态点任何按钮都立即回到队列；
- 重学步骤 `relearning_steps = (0s)`（用户确认）：重学状态立即回到队列；
- `enable_fuzzing = true`（FSRS 默认，用户确认）：间隔带少量随机抖动；
- 最大间隔 `maximum_interval = 365` 天（1 年，用户确认）。

## 4. 状态存储

- 每张卡在 `cards.fsrs_state` 保存 FSRS `Card` 的 JSON
  （state、step、stability、difficulty、due、last_review）；
- 每条新评分在 `review_logs.fsrs_review_log` 保存 FSRS `ReviewLog` 的 JSON，
  供以后参数优化/重排使用；
- `review_logs.previous_fsrs_state` 保存评分前快照，供“撤回”恢复；
- 对外接口保留 `state / interval_days / due_at / learning_step` 等旧字段，
  数值由 FSRS 状态同步而来，前端和队列逻辑不需要大改。

### 存量数据迁移

- 已有“待复习卡”（`due_at` 非空）迁移时按当前 `interval_days` 近似初始化：
  `stability = max(1, interval_days)`、`difficulty = 5.0`，
  复习卡 `state=Review`、学习中卡 `state=Learning/Relearning`；
- 新卡（`due_at` 为空）不预置状态，第一次评分时按 FSRS 学习卡初始化；
- 首次切换后前几次间隔可能与旧算法不同，这是正常冷启动；
  复习几次后 FSRS 会按真实表现收敛到个人节奏。

## 5. 队列规则（不变）

- 只有到期的卡（`due_at <= now`）进入队列；
- 队列固定顺序：到期复习 → 今日新学 → 学习中的卡（排最后）；
- 学习中的卡（含刚评「重来/困难」的卡）排到队尾，前端会话内同样追加到队尾，
  因此页面显示与刷新后的服务端队列一致（刷新前后、手机端与电脑端顺序相同）；
- 刷新页面不随机打乱顺序；
- 新卡排在最后，旧卡没学完不会先出现新卡。
- 「继续学习」抽出的加学卡写入当天分配（`daily_new_assignments.is_extra`），
  没学完时刷新仍保留在今日新学队列，直到全部学完。
- 新用户的每日新学习默认数量为 10 张；这是可自行修改的学习偏好，不改变
  FSRS 评分、间隔或队列顺序，也不覆盖已有用户的已保存设置。

## 6. 预览、预测与记忆曲线

- 四个按钮的 `rating_previews` 直接用 FSRS 在副本上计算，不污染真实状态；
- 仪表盘 30 天到期预测：按每张卡当前 FSRS 状态，模拟每次评分都为“正确”
  后的到期日；
- 记忆曲线：用 FSRS 的 retrievability 公式按稳定度计算未来保留率。

## 7. 修改流程

任何涉及以下内容的改动，必须先更新本文档并说明原因：

- 评分档位、评分到 FSRS Rating 的映射、目标保持率；
- 学习/重学步骤、最大间隔、是否启用 fuzzing；
- FSRS 状态字段的存取格式或存量迁移规则；
- 队列排序、新卡与旧卡出现顺序；
- 到期时间计算与日期对齐。
